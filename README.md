# Mi práctica de Git y GitHub

## Lo que aprendí en el curso

Durante el curso aprendí los siguientes temas:

- Crear repositorios y administrar proyectos con GitHub.
- Utilizar comandos de Git para guardar cambios.
- Trabajar con ramas, issues y pull requests.

Enlace de aprendizaje: [Microsoft Learn](https://learn.microsoft.com)

### Comandos básicos de Git

```bash
git init
git add .
git commit -m "Primer commit"
```
